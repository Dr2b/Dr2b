## Defense in depth

No single barrier holds — not skin, not a firewall. Every defence worth trusting, biological or digital, is layered, observable, and learns from whatever got through.

<p align="center">
  <img src="./assets/github-profile/defense-in-depth.svg" width="100%" alt="Fig. 02 — Defense in depth, read three ways. L1 barrier: skin and mucosa / edge and interface (TLS, input validation) / hardening. L2 innate: innate immunity / gateway and identity (authN/Z, rate limits) / detection (telemetry, alerting, triage). L3 adaptive: adaptive immunity / services and data (least privilege, isolation) / incident response (contain, eradicate, recover). L4 memory: immunological memory / logs and observability / lessons learned (rules, playbooks, intel).">
</p>

## Immune patrol

Every square is one day of my GitHub activity, read as living tissue. Each morning a new outbreak is seeded into it: antigens appear and spread to neighbouring days, and a phagocyte hunts every one down until the tissue reads *all clear*. It is regenerated daily by a GitHub Action, so no two days play the same.
